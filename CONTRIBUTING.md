# Contributing

Open an issue before changing the template's permissions, external endpoints, privacy behavior, or dataLayer contract.

Before submitting a pull request, import `template.tpl` into the Google Tag Manager template editor and run every test in the **Tests** tab. Describe the tested container context and any permission changes in the pull request.

Official maintainer commits, pushes, and releases follow the [FindIP public maintenance identity policy](https://github.com/findip-net/.github/blob/main/CONTRIBUTING.md#maintainer-publishing-identity).
